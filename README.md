# Django CRM App

A Django-based Customer Relationship Management (CRM) application that allows users to manage customers and orders efficiently.  
This project uses MySQL for persistent data storage and demonstrates Django’s core features such as authentication, model relationships, and admin customization.

## Features

- User registration and login
- Dashboard with customer and order listings
- Add, update, and delete customer orders
- Admin panel customization
- MySQL database integration
